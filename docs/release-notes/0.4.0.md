## Git Rebase Visual 0.4.0

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏中安全地重排、编辑、锁定和推送 commit，支持 AI commit message、stash 与暂存区追加。

> 来源：Git tag `v0.4.0` · GitHub Actions 自动构建 · 已通过 TypeScript 检查、真实 Git 集成测试、覆盖率测试和 VSIX 内容校验。

### ✨ 新功能与增强（0.4.0）

- **暂存区恢复可见性**：auto-stash 或 append 恢复发生冲突时，提示精确的 `stash@{n}`、短 SHA 和可执行的手动恢复命令；新增 `Git Rebase: View Stash List`，优先打开 Git stash 视图，不可用时写入 **Git Rebase Visual** Output。
- **高效提交身份识别**：patch-id 增加 `<repoRoot>:<hash>` session cache，避免 hover、锁定和 push guard 重复计算；root commit 也能正确计算 patch-id。
- **结构化变更统计**：hover 统计优先使用 Git `--numstat`，更可靠地处理文件数、插入、删除和二进制/重命名条目。
- **环境与凭据基础设施**：启动时检查 Git 最低版本；SecretStorage 访问管线已接入，后续 API key 迁移具备安全基础。

### 🐛 修复（0.4.0）

- **历史改写与 UI 状态竞态**：后台刷新与历史操作采用 generation/busy 保护；过期 Webview 消息不会静默重写历史。
- **append 安全性**：锁定 commit 不能追加暂存区；已推送目标需要显式确认后才允许改写。
- **LLM 稳定性**：AI message 支持 SSE 流式回填、超时、取消和安全错误分类；中途取消/超时不会让 response read 永久挂起或产生未处理 rejection。
- **测试稳定性**：patch-id 跨重写测试改用 `commit-tree` 构造确定性同 diff clone，避免快速 CI 中同秒 cherry-pick 复用 hash 的 flaky 断言。

### 🔒 可靠性与质量

- 新增真实 bare remote 测试，验证 `--force-with-lease` 在远端并发变化时拒绝覆盖，以及 lockedInPush 的锁定拦截。
- 新增 append 守卫、stash 恢复、LLM 流式取消/超时与 SecretStorage 访问器测试。
- 本版测试套件扩展至 40 项，并启用 VSIX 内容、`RELEASE.md` 版本记录等发布门禁。

### 使用方式

- 下载 `git-rebase-visual-0.4.0.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.4.0.vsix`。

### 功能总览

- **交互式 rebase**：拖拽重排、edit/reword/drop、冲突 Continue/Abort；
- **提交保护**：patch-id 锁定、Push guard、`--force-with-lease`；
- **工作区辅助**：auto-stash、stash 列表、将暂存区追加到已有 commit；
- **AI message**：流式生成、超时、取消与 trailer 保留；
- **质量保障**：真实 Git 集成测试、Output 诊断、VSIX 内容门禁。
