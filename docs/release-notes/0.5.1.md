## Git Rebase Visual 0.5.1

Visual interactive-rebase extension for VS Code: safely reorder, edit, lock and push commits from a sidebar, with AI commit messages, stash support and staged-append workflows.

> Source: Git tag `v0.5.1` · GitHub Actions automated build · CI passed `npm run test:release`, VSIX content verification and release-note verification.

### 🐛 Fixes (0.5.1)

- **Terminal `git switch` / `git stash` index-lock contention**: the visible Git Rebase panel periodically refreshes staged/unstaged state with `git status`. Git may opportunistically refresh index metadata during status and briefly create `.git/index.lock`, racing terminal write operations. **Fixed**: background status reads now set `GIT_OPTIONAL_LOCKS=0`, preserving correct porcelain results while preventing Git's optional index-cache lock refresh. This setting is deliberately restricted to read-only status queries; rebase, stash, commit, push and other write operations keep normal Git locking.
- **Regression coverage**: added a real temporary-repository test that creates `index.lock` and verifies both `workingStatus()` and `isDirty()` still report correct state with the optional-lock safeguard enabled.

### 🔒 Reliability

- Git Rebase Visual continues to use normal Git locks for all history-changing and worktree-writing operations.
- Existing rebase safety protections remain unchanged: locked commits cannot be dropped directly, unresolved conflicts block Continue, append Abort avoids duplicate stash restoration, and Compose retains text on reword failure/pause.

### Usage

- Download `git-rebase-visual-0.5.1.vsix`.
- VS Code: Extensions → `...` → **Install from VSIX...**.
- Command line: `code --install-extension git-rebase-visual-0.5.1.vsix`.

### Highlights

- Interactive rebase: oldest-first Base → HEAD timeline, drag reorder, edit/reword/drop, conflict-aware Continue/Abort.
- Commit protection: patch-id locks, Push guard and `--force-with-lease`.
- Worktree support: auto-stash, exact stash recovery hints, stash list, staged append to an existing commit.
- AI messages: streaming generation, deadline, cancellation and trailer preservation.
- Quality gates: real Git integration tests, Output diagnostics and VSIX content validation.
