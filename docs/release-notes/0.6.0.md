## Git Rebase Visual 0.6.0

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏与编辑器区中安全地重排、编辑、合并、锁定和推送 commit，支持 AI commit message、stash、暂存区追加与可验证的历史恢复。

> 来源：Git tag `v0.6.0` · GitHub Actions 自动构建 · 已通过 `npm run test:release`、VSIX 内容校验与版本化中文 Release body 校验。

### ✨ 新功能（0.6.0）

- **受控 Undo 与操作历史**：每次成功历史改写前创建私有 `refs/gitRebaseVisual/undo/<id>` checkpoint，并记录仓库、分支、before/after tip 与操作类型。工具栏、成功结果和历史入口可触发 Undo；Undo 会检查 rebase、当前分支、HEAD、工作区、checkpoint 和已推送风险，优先使用 `git reset --keep`，不会把不安全的 `ORIG_HEAD + reset --hard` 伪装成一键恢复。
- **真实 rebase 进度与待重放状态**：面板显示步骤 `N/M`、edit/conflict/paused 原因、当前步骤与待重放 commit。待重放项明确标记“hash 将变化”，不再把原 hash 表现为已生成的稳定结果。外部 rebase 无法可靠解析时会显示 unknown，而非虚构进度。
- **edit 停靠工作区**：停靠在 `edit` commit 时，面板提供针对当前停靠点的 Amend、新建 commit、仅生成 message 入口，并显示 staged/unstaged 文件数；宿主会严格校验 pause reason、stopped HEAD、冲突和暂存状态。
- **冲突专用 Skip**：Skip 仅在 conflict pause 可用，弹窗明确展示将丢弃的 commit/patch 后果；edit stop 不会错误提供 Skip。
- **Commit 决策工具**：右键菜单新增复制 message、查看受控只读 diff、squash、fixup；首 commit、locked 当前/前驱、rebase 中等不安全场景会禁用并说明原因。
- **编辑器区 Compose Panel**：commit message 编辑迁移到独立 WebviewPanel，支持 subject/body、50/72 字符提示、72 列参考、原 message/trailer 折叠、AI 生成状态、取消、替换、追加、恢复生成前 draft 和 Apply 失败保留输入。
- **作者与状态可视化**：作者 email 生成稳定颜色和首字母；edit 为信息蓝、conflict 为错误红、locked 为警告橙、pending 为可读的待重放状态。颜色始终有图标、文字和 ARIA 辅助表达。
- **高效操作与可访问性**：grip-only 拖拽，文本可选择；列表/菜单键盘导航、Space pickup/drop、Arrow 移动、Alt+Arrow 快速移动、菜单 roving focus、状态栏 rebase 进度与点击回到面板。
- **上下文与规模管理**：显示 branch、upstream、ahead/behind、范围信息；支持搜索、multi-select、连续 locked run 安全折叠、staged 主操作与危险 `git add -A` 次级操作。

### 🐛 修复（0.6.0）

- **Undo journal 跨仓库误用**：操作历史现在按 repository root 隔离；journal 淘汰时清理对应私有 undo ref，避免长期累积。
- **rebase todo 进度虚构**：进度 parser 现在识别 `exec`、`break`、`label`、`reset`、`merge`、`update-ref` 等 todo 命令；未知语法整体降级为 unknown，不伪造 pending hash。
- **Compose `messageOnly` 误提交**：仅生成 message 模式现在只复制/保留 draft，不会意外执行 commit。
- **ComposePanel 生命周期**：修复 Panel 重复打开/关闭后的消息监听释放，避免遗留 listener 或陈旧 session。
- **历史安全回归**：继续保留 locked Drop 防护、冲突 Continue 复查、append Abort 不重复恢复 stash、reword 暂停保留输入。

### 🔒 可靠性与质量

- 新增 Undo、rebase progress、squash/fixup、Compose draft 等测试；真实 Git 集成测试覆盖冲突、Abort、Skip、锁、合并与恢复关键路径。
- `fixup` 回归测试确认 fixup commit 的 message 会按 Git 语义丢弃，而 squash 保留双方 message。
- 全量测试、类型检查、VSIX 内容校验和中文 Release body 检查均为发布门禁。

### 使用方式

- 下载 `git-rebase-visual-0.6.0.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.6.0.vsix`。
