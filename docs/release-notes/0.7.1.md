## Git Rebase Visual 0.7.1

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏中安全地重排、编辑、锁定和推送 commit，并提供工作区恢复、只读 Diff、AI commit message、stash 与受控 Undo。

> 来源：Git tag `v0.7.1` · GitHub Actions 自动构建 · CI 将执行 `npm run test:release`、VSIX 内容校验与版本记录校验。

### ✨ 新功能（0.7.1）

- **不遮挡时间线的 Commit Inspector**：悬停 commit 约 0.4 秒后，完整作者、时间、变更统计和 message 会显示在相邻编辑器区；可将指针移到右侧阅读或复制，不再用侧栏浮层遮挡列表。右击 commit 或使用 `Shift+F10` / Menu 键会在同一 inspector 打开操作；单项操作中“停靠在此 (edit)”位于首位。
- **更清晰的文件暂存管理**：文件行默认显示文件名与目录，hover/focus 时才显示 stage、restore 等紧凑操作；点击文件行即可打开 VS Code 左右 Diff，不再重复显示打开 Diff 图标。Changes 支持全部暂存和全部恢复，Staged Changes 支持全部撤销暂存与基于暂存内容生成 AI commit message。
- **更稳定的拖拽和锁定摘要**：普通工作区状态刷新不会错误地让正在进行的拖拽变为过期；连续锁定 commit 使用紧凑摘要，展开后移除贯穿整组的长黄色边线。

### 🐛 修复（0.7.1）

- **Commit Inspector 关闭后不能可靠重开**：关闭、重新打开、延迟的旧 panel dispose 和 extension dispose 现在采用独立生命周期 ownership；旧回调不会清除新 inspector，右键和键盘 Context Menu 可持续使用。
- **慢速 hover 详情覆盖明确操作**：hover preview 与右键单项/批量操作使用独立 session；慢速 Git 详情或遗留 hover 事件不能覆盖或关闭较新的操作面板。
- **Inspector 获取焦点即关闭**：只有真实普通 TextEditor 的活动/选择变化才关闭 inspector；WebviewPanel 自身的焦点过渡不再使操作按钮失效。
- **手动 Refresh 没有成功反馈**：侧栏、视图标题和命令 Palette 的 Refresh 成功后均显示“已刷新”；自动轮询和初始加载保持安静。
- **确认期间文件状态变化仍可能删除未跟踪文件**：删除未跟踪文件在确认后会重新读取 Git 状态；文件被暂存或变成其他状态时拒绝删除。

### 🔒 安全与可靠性

- 历史重排仍由 extension host 重新验证完整 commit hash、canonical revision、当前顺序和锁定状态；UI 的显示/禁用状态不被当作安全边界。
- 文件级和批量 stage、restore、discard、unstage 均在宿主重新读取结构化 porcelain 状态，并经 mutation gate 串行化；批量 discard 与 unstage 需要明确确认，unstage 不改变工作区内容。
- 新增 canonical snapshot、Commit Inspector panel lifecycle/adapter、preview ownership、dismiss policy、Refresh feedback 和工作区批量操作的回归测试。

### 使用方式

- 下载 `git-rebase-visual-0.7.1.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.7.1.vsix`。

### 功能总览

- 交互式 rebase：拖拽重排、Alt+Arrow 重排、edit/reword/squash/fixup/drop、冲突 Continue/Abort；
- 提交保护：patch-id 锁定、Push guard、`--force-with-lease` 与受控 Undo；
- 工作区辅助：Staged/Changes 文件列表、单文件与批量 stage/restore/unstage、VS Code 左右 Diff、auto-stash 与 stash list；
- AI message：流式生成、deadline、取消、trailer 保留与 staged-only commit；
- 诊断与质量：OutputChannel、真实 Git 集成测试、webview DOM 回归、VSIX 内容门禁。
