## Git Rebase Visual 0.7.0

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏中安全地重排、编辑、锁定和推送 commit，并提供工作区恢复、只读 Diff、AI commit message、stash 与受控 Undo。

> 来源：Git tag `v0.7.0` · GitHub Actions 自动构建 · CI 已通过 `npm run test:release`、VSIX 内容校验与版本记录校验。

### ✨ 新功能（0.7.0）

- **更准确的 commit 多选与右键操作**：普通点击只切换当前上下文，Ctrl/Cmd+点击才建立多选；右击未选中的 commit 会先切换为该单项，右击已选中的行才保留批量集合，避免批量锁定、删除或生成 Diff 的目标与鼠标目标不一致。
- **连续区间的只读生成 Diff**：右键可为单个 commit 或连续多选区间生成 Diff。非连续多选会明确禁用该项并提示原因；宿主也会独立拒绝过期、未知、重复或有空洞的请求。生成结果使用扩展私有的只读虚拟文档，内容在生成时冻结，不会成为可编辑的 `untitled:` 草稿。
- **工作区恢复操作补全**：在既有 Staged Changes / Changes 结构化文件列表上补齐单文件 restore 和经确认删除未跟踪文件；操作后仍复用 VS Code 左右 Diff 检查 working/index/HEAD 的差异，不会把恢复误当成静默批量清理。
- **更可靠的拖拽与键盘重排**：pointer/native drag 与 Alt+↑/↓ 均携带开始操作时的完整 canonical order 与 revision。拖拽期间发生刷新时，旧手势不会按新列表重新解释，所有重排仍须经过宿主快照、锁定状态和确认校验。
- **搜索与无障碍细节**：支持 `author:`、`msg:`、`hash:` 和 `hash:0x...` 筛选；中文 IME composition 期间不会重复输入或触发重排快捷键。作者标识使用稳定 palette 和可区分文字前缀，forced-colors 下也不只依赖颜色。

### 🐛 修复（0.7.0）

- **暂停 rebase 时文件写入未被统一保护**：单文件暂存与恢复现被识别为真实 mutation，进入宿主 busy 串行化；edit stop 中仅由明确 allow-list 放行，而滚动、选择、IME、刷新和只读 Diff 不会再产生无意义的暂停告警。
- **rename 后仍有工作区修改时单文件暂存失败**：对于 `XY=RM`，仅将当前 working-side 路径交给 `git add -A --`，不再把已消失的旧 rename 路径作为 pathspec。
- **LLM HTTP 测试偶发 `fetch failed: bad port`**：共享测试 server 会在 `listen(0)` 后检查 Fetch Standard 的完整 bad-port table；命中禁用端口时先关闭 listener 再重试，避免 Windows 动态端口分配导致 deadline、取消和 SSE 测试在请求前随机失败。

### 🔒 安全与可靠性

- 历史改写、批量操作和生成 Diff 均在 extension host 重新验证完整 hash、当前 snapshot/revision、连续性和锁定状态；webview 禁用状态不能替代宿主校验。
- Git 内容和生成 Diff URI 只携带受限 opaque token，不暴露仓库路径、Git ref 或命令参数；快照具备仓库失效、TTL、LRU 与 extension dispose 清理。
- 本版本新增 webview DOM、生成 Diff snapshot、mutation gate 与 staged-restore 真实 Git 回归；自动测试套件扩展至 **120 项**。

### 使用方式

- 下载 `git-rebase-visual-0.7.0.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.7.0.vsix`。

### 功能总览

- 交互式 rebase：拖拽重排、Alt+Arrow 重排、edit/reword/squash/fixup/drop、冲突 Continue/Abort；
- 提交保护：patch-id 锁定、Push guard、`--force-with-lease` 与受控 Undo；
- 工作区辅助：Staged/Changes 文件列表、单文件 stage/restore、VS Code 左右 Diff、auto-stash 与 stash list；
- AI message：流式生成、deadline、取消、trailer 保留与 draft-only 策略；
- 诊断与质量：OutputChannel、真实 Git 集成测试、webview DOM 回归、VSIX 内容门禁。
