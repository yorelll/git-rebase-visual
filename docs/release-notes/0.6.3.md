## Git Rebase Visual 0.6.3

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏与编辑器区中安全地重排、编辑、合并、锁定和推送 commit，支持 AI commit message、stash、暂存区追加与可验证的历史恢复。

> 来源：Git tag `v0.6.3` · GitHub Actions 自动构建 · 已通过 `npm run test:release`、VSIX 内容校验与版本化中文 Release body 校验。

### ✨ 新功能（0.6.3）

- **文件级工作区管理**：更多提交选项显示 Git 结构化状态文件清单，区分 staged / working / untracked、Modify/Add/Delete/Rename/Conflict。可对单个 working/untracked 文件执行安全暂存；路径含空格、删除、rename 和同文件 staged+unstaged 都有正确处理。
- **真正的 VS Code 左右 Diff**：点击工作区文件以 index ↔ working 或 HEAD ↔ index 打开左右 Diff；右键、hover 和 Compose 的“打开变更…”也使用 parent ↔ commit 文件级左右 Diff。多文件 commit 提供文件选择；root/add/delete/rename/binary/merge 有受控 fallback。
- **受控 Git 内容 provider**：worktree 与 commit Diff 共用 opaque request store；URI 不暴露 repository/ref/path，提供 authority 限制、TTL、LRU、仓库失效和 extension dispose cleanup。
- **强搜索与选择**：支持 `author:`、`msg:`、`hash:` 以及 `hash:0x...`；未知前缀保留全文搜索；支持中文 IME composition、不重复字符，显示结果计数和清除入口。
- **可靠重排兜底**：grip pointer drag 与原生 drag 使用同一个 canonical reorder intent；`Alt+↑/↓` 可将已选 commit 上下移动一位，仍经宿主确认和完整 order 验证。

### 🐛 修复（0.6.3）

- **中文搜索输入重复字符/失焦**：composition 期间不重建 search input，compositionend 后仅应用最终文字；自动 refresh 后恢复焦点与 cursor selection。
- **成功通知推动 commit 列表**：成功反馈改为复用固定高度 branch context 区的 overlay toast，显示/消失均不改变列表文档流；warning/error 仍为系统通知，长任务使用 SourceControl progress。
- **搜索与更多提交选项自动关闭**：refresh 后恢复 filter、locked run 展开、more options 展开和搜索 selection。
- **edit stop 无法完成 amend/new 提交**：停靠横幅实际渲染 Compose 入口；真实 Git 写入再次验证 edit stop、staged 内容、冲突和目标。Amend 保留 trailer，新 commit 不继承目标 trailer；AI 在 rebase 中仅生成 draft，不绕过写入 guard。
- **rename + working 修改单文件暂存失败**：`XY=RM` 时不再把已消失的 original rename path 传给 `git add -A`；只 stage 当前 working-side path，并有真实 Git 回归测试。
- **嵌套 commit 文件无法打开左右 Diff**：commit diff-tree 枚举加入 `-r`，确保 `nested/file.txt` 而非 `nested` 目录被作为可比较文件。

### 🔒 可靠性与质量

- 所有 rebase mutation 继续使用 host-side hash、revision、lock、range、canonical order 和 patch-id continuity 校验。
- 新增 porcelain v2 状态、单文件 stage、commit/worktree Diff resolver、IME、pointer drag、scroll 协议、Compose session/edit-stop 写入、nested commit Diff 等测试。
- 全套测试扩展至 **103 项**。
