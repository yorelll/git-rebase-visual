## Git Rebase Visual 0.5.0

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏中安全地重排、编辑、锁定和推送 commit，支持 AI commit message、stash 与暂存区追加。

> 来源：Git tag `v0.5.0` · GitHub Actions 自动构建 · 已通过 TypeScript 检查、48 项真实 Git/逻辑/HTTP mock 测试、覆盖率测试和 VSIX 内容校验。

### ✨ 新功能与界面增强（0.5.0）

- **更清晰的提交时间轴**：保持与 Git interactive-rebase todo 一致的 oldest-first 顺序，新增 `Base / 较早` 与 `HEAD / 较新` 方向标记、拖拽 grip、插入位置说明和历史改写确认。
- **更易阅读的侧边栏列表**：commit subject 成为最多两行的主信息；hash、作者和日期显示在次级 metadata 行；移除无语义的 hash HSL 着色，使用中性时间轴装饰。
- **更安全的右键菜单**：增加目标 commit header、分组和危险操作层级；Drop 置底并使用危险语义色；锁定、暂无暂存内容或 rebase 中的 append 操作会禁用并说明原因。
- **工作区范围提示**：显示 staged/unstaged 文件数；工作区生成并提交会明确提示将执行 `git add -A`；未配置 LLM 时保留设置入口。
- **基础键盘与无障碍支持**：`lang="zh-CN"`、ARIA 语义、focus-visible、Escape、Shift+F10/Menu 键菜单调用、Ctrl/Cmd+Enter 应用 commit message。

### 🐛 修复（0.5.0）

- **锁定 commit 的 Drop 安全性**：锁定 commit 不能直接删除，避免 rebase 冲突、失败或 Abort 后 commit 回到历史但锁已经丢失。
- **冲突 Continue 反馈**：暂停 rebase 时实时显示冲突文件与数量；未解决冲突会禁用 Continue，宿主在 Continue 前再次检查 Git 状态；不再静默失败。
- **错误的 edit-stop 显示**：不再仅依赖 stale `stopped-sha` 判断 edit stop，避免将 replay conflict 错标为用户主动停靠。
- **append Abort 双重 stash 恢复**：修复 replay conflict 后 Abort 时完整 snapshot 与 keep-index stash 重复应用，避免未暂存内容冲突与 pending stash 残留。
- **Compose 输入保留**：Apply 期间对话框保留，只有 Git 成功后关闭；普通 reword/rebase 暂停或失败时保留手写 message 并在 dialog 内显示错误。

### 🔒 可靠性与质量

- 新增真实 Git rebase 安全测试：locked Drop conflict/Abort、冲突 Continue、edit-stop Abort、暂停状态派生。
- 成功历史改写将记录 operation、old tip、new tip 和影响范围到 Output/通知；不提供不安全的 ORIG_HEAD 一键 reset。
- 测试套件扩展至 48 项。

### 使用方式

- 下载 `git-rebase-visual-0.5.0.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.5.0.vsix`。

### 功能总览

- **交互式 rebase**：Base → HEAD 时间轴、拖拽重排、edit/reword/drop、冲突感知 Continue/Abort；
- **提交保护**：patch-id 锁定、Push guard、`--force-with-lease`；
- **工作区辅助**：auto-stash、精确 stash 恢复提示、stash 列表、将暂存区追加到已有 commit；
- **AI message**：流式生成、超时、取消与 trailer 保留；
- **质量保障**：真实 Git 集成测试、Output 诊断、VSIX 内容门禁。
