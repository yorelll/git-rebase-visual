## Git Rebase Visual 0.6.1

用于 VS Code 的可视化交互式 Git rebase 扩展：在侧边栏与编辑器区中安全地重排、编辑、合并、锁定和推送 commit，支持 AI commit message、stash、暂存区追加与可验证的历史恢复。

> 来源：Git tag `v0.6.1` · GitHub Actions 自动构建 · 已通过 `npm run test:release`、VSIX 内容校验与版本化中文 Release body 校验。

### 🐛 修复（0.6.1）

- **Compose 原 message / trailer 显示为空**：首次创建或 Webview reload 时，宿主可能在页面 message listener 安装前发送 Compose payload，造成原始 message、trailer 和初始 draft 丢失。**修复**：Compose Panel 引入 `composeReady` 握手和最新 payload delivery queue；listener 就绪、重复 ready 或 reload 后都重发最新 payload。
- **连续 locked commit 展开后自动关闭**：状态轮询 refresh 会重建列表 DOM，原生 `<details>` 展开状态随之丢失。**修复**：按稳定 locked-run hash key 保存展开状态，refresh 后恢复；仅连续 **≥3** 个 locked commit 且设置开启时折叠。
- **重排时必须展开 locked run**：折叠摘要此前无法作为 drop target。**修复**：拖动非 locked commit 到摘要上/下半区，分别完整插入该 run 前/后；仍发送完整 canonical todo order 并由宿主验证。
- **搜索与“更多提交选项”自动失焦/收起**：自动 refresh 重建 DOM 后丢失输入焦点、selection 和 `<details>` open 状态。**修复**：渲染前捕获、渲染后恢复搜索焦点/光标区间，保存更多选项展开状态。
- **通知距离用户视线远且会堆叠**：复制、stash 等成功消息全部使用右下角 10 秒系统进度通知。**修复**：成功类反馈改为面板顶部 inline toast（默认 2.5 秒、替换不堆叠）；warning/error 继续使用系统通知且不由插件自动关闭；Push、AI 与 rebase 使用 SourceControl progress。
- **缺少分支上下文**：面板无法直接看出 branch、upstream、ahead/behind 和范围。**修复**：新增 context bar；正常分支、无 upstream 和 detached rebase 都给出明确文案。
- **edit 停靠“仅生成 message”可能提交**：该入口未携带 draft-only 标识，可能走实际 Apply 路径。**修复**：显式使用 `messageOnly: true`；宿主仅允许暂停 rebase 内的 staged/working draft-only Compose，所有 apply/commit 路径仍受严格白名单保护。

### 🔒 可靠性与质量

- 新增 Compose delivery state、暂停 Compose policy、branch/upstream/ahead/behind integration、locked-run/settings/搜索焦点等回归覆盖。
- 测试套件扩展至 70 项；host-side validation、完整 todo order、locked guard 和 rebase mutation whitelist 保持不变。
