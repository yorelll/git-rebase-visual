## Git Rebase Visual 0.7.2

用于 VS Code 的可视化交互式 Git rebase 扩展：使用原生 TreeView 安全地重排、编辑、锁定和推送 commit，提供工作区恢复、只读 Diff、AI commit message、stash 与受控 Undo。

> 来源：Git tag `v0.7.2` · GitHub Actions 自动构建 · CI 将执行 `npm run test:release`、VSIX 内容校验与版本记录校验。

### ✨ 新功能（0.7.2）

- **原生提交列表交互**：commit 的悬停详情、右键菜单、多选和拖拽均使用 VS Code 原生 TreeView。普通点击只选择行，Ctrl/Cmd+点击可建立多选，不会打开 editor Tab；不再创建 Commit Inspector 编辑器页或上下文面板。
- **完整的原生操作入口**：暂停 rebase 的 Continue/Abort/Skip、edit stop 的 amend/new/draft、squash/fixup、工作区全部暂存/恢复/撤销暂存、单文件 Diff/暂存/恢复，以及 locked/batch 项的复制和只读 Diff 都可从原生菜单访问。
- **工作区 AI message**：右键 **Changes** 标题即可基于未暂存工作区改动生成 AI commit message；右键 **Staged Changes** 可基于暂存内容生成。暂停 rebase 时两者只生成可复制草稿、不提交。
- **原生锁定摘要与末端拖拽**：连续锁定 commit 可折叠为 `🔒 : N lock · no push` 摘要。原生拖拽支持放到列表 end 边界，令 commit 成为最新一项。

### 🐛 修复（0.7.2）

- **Git 元数据影响 tooltip 格式**：commit subject、作者、日期、统计和完整 message 现在作为纯文本写入原生 tooltip，仓库中的 Markdown/链接字符不会被解释。
- **批量命令可由无关行触发**：批量 Lock、Drop 和 Generate Diff 现在要求命令参数中的 commit 属于当前多选集合；否则宿主拒绝请求。
- **锁定项丢失只读操作**：locked、batch 和 locked-batch 行均保留 Copy Hash、Copy Message、Open Diff 与 Generate Diff；历史改写操作仍在锁定或不允许的批次中隐藏。
- **未跟踪文件确认期间状态变化**：删除仍由专用 host 路径处理，modal 确认后重新读取 porcelain 状态；文件已暂存、已跟踪或不存在时拒绝删除。

### 🔒 安全与可靠性

- 原生 DnD、生成 Diff 和批量操作均携带或重建当前 canonical 数据；宿主在写入或创建只读快照前验证完整顺序、revision、selection、连续性及锁定状态。
- 拖拽确认框关闭前后都会再次验证，过期 revision、锁定 source/anchor 和伪造顺序不会启动 rebase。
- immutable commit 详情按选中行延迟读取并使用有界 LRU 缓存，状态轮询不会为全历史重复启动 detail 子进程。
- 本版本增加 native TreeItem、tooltip 注入、working AI policy、batch target、原生 DnD end boundary、锁定批次与 manifest 可达性回归测试。

### 使用方式

- 下载 `git-rebase-visual-0.7.2.vsix`。
- VS Code：扩展面板 → `...` → **Install from VSIX...**。
- 命令行：`code --install-extension git-rebase-visual-0.7.2.vsix`。

### 功能总览

- 交互式 rebase：原生拖拽重排（含 end 边界）、edit/reword/squash/fixup/drop、冲突 Continue/Abort/Skip；
- 提交保护：patch-id 锁定、锁定摘要、Push guard 与 `--force-with-lease`；
- 工作区辅助：Staged/Changes 原生菜单、单文件与批量 stage/restore/unstage、确认并重验证的未跟踪文件删除、VS Code 左右 Diff；
- AI message：commit、staged 与 working 入口，流式生成、deadline、取消、暂停时 draft-only 与 trailer 保留；
- 诊断与质量：OutputChannel、真实 Git 集成测试、原生 TreeView 回归、VSIX 内容门禁。
